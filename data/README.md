# Data availability

This GitHub repository contains source code only. It does not redistribute GTEx donor-level expression data, trained checkpoints, prediction matrices, or the completed 10.4-GB HDF5 resource.

The completed GTEx Analysis V11 resource and its documentation are associated with the reserved Zenodo version DOI [`10.5281/zenodo.24421141`](https://doi.org/10.5281/zenodo.24421141). The record is not publicly available until its owners publish the current Zenodo draft.

Access to original GTEx data remains subject to the GTEx Portal terms and any applicable data-access requirements.


## Expected input layout for training and evaluation

GTEx expression data are not redistributed here. Users with GTEx access should place a preprocessed cache at:

```text
data/gtex_phase4_20000genes_compat/
  expr.npy             float32 array, samples x 20,000 genes, log1p(TPM)
  meta.csv             index = GTEx sample ID (e.g. GTEX-XXXX-...), column tissue_idx (integer)
  tissue_encoder.json  {"<GTEx tissue name>": tissue_idx, ...}
```

Genes are the 20,000 highest-variance GTEx v11 genes; their order must match the gene annotation table released with the Zenodo resource (`dorian_gtex_v11_gene_annotations.csv`, column `column_index`). Donor IDs are derived from the first two fields of the sample ID, and the donor split is generated by the code with seed 42.
